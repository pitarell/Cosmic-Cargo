# Cosmic Cargo para Android

Aplicativo Android offline do protótipo Cosmic Cargo 0.28. O jogo roda em uma WebView nativa, em tela cheia e orientação paisagem, com JavaScript e armazenamento local habilitados. Nenhuma permissão de internet é solicitada.

O APK de teste está em `dist/Cosmic-Cargo-0.28-debug.apk`. Para desenvolvimento, abra esta pasta no Android Studio e execute o módulo `app`. O projeto usa `compileSdk 36`, `minSdk 23`, `targetSdk 36` e o identificador `com.cosmiccargo.game`.

O APK de teste é assinado com uma chave de desenvolvimento criada apenas para este protótipo. Uma publicação na Google Play exige uma chave de lançamento própria, revisão de políticas, testes em aparelhos e geração de um Android App Bundle assinado.
