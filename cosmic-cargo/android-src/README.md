# Cosmic Cargo para Android 0.43

Aplicativo Android offline em WebView, tela cheia e orientação paisagem. A edição móvel contém naves e sistemas até a categoria 3 e não inclui contratações nem viagens automáticas. JavaScript, armazenamento local e controles touch ficam habilitados; nenhuma permissão de internet é solicitada.

O APK de teste está em `../dist/Cosmic-Cargo-Android-0.43.apk`. O projeto usa `compileSdk 36`, `minSdk 23`, `targetSdk 36` e o identificador `com.cosmiccargo.game`. Para publicação, abra esta pasta no Android Studio, configure uma chave de lançamento própria e gere um Android App Bundle assinado.
