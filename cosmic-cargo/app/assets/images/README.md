# Imagens do Cosmic Cargo

Recursos visuais gerados especificamente para o jogo a partir dos prompts de direção de arte fornecidos pelo autor. As imagens de `ships/dealership` são as pranchas de apresentação; `ships/sprites` contém as versões simplificadas usadas durante o pouso. Em `destinations`, cada local possui uma arte de apresentação e uma arte de aproximação/pouso.
